# Hana Desk Pet

一个跟着 Hana 干活的桌面宠物。

Hana 在想事情，它歪头思考；Hana 在读文件，它翻书；Hana 在跑命令，它跑起来；你插的话被丢了，它会惊讶一下。形象用 CrossPet 原版立绘，7 个角色、197 张透明姿态图（193 张上游原图 + 4 张本地生成的补充）。

> **这是 demo。** 给群友玩玩看的，不是产品。没做签名公证，没做安全加固，只支持 macOS。请按玩具的预期使用。

## 它是什么

两个独立程序，走本机回环通信：

```
Hana
 └─ 桌宠控制台（Hana App）
      │  只读：会话标题、Agent、工具名、状态、时间戳
      │  http://127.0.0.1:43127  /v3/*
      ▼
    桌宠（独立 macOS 原生 App，透明悬浮窗，只画角色）
```

控制台订阅 Hana 的会话事件、维护脱敏状态快照、管理角色和会话绑定；桌宠负责把状态翻成姿态、做转场、处理拖动和右键菜单。

控制台里能看到桌宠**此刻真正在摆的姿势**——不是根据最近事件猜的，是桌宠通过 `GET /v3/state` 回报的最终结果（含回退后的替代图，会打角标）。桌宠没开着的时候这里会明说「未连接」，不会拿上一次的姿态糊弄你。

它不是 CrossPet 的适配器，也不读写 CrossPet 的任何配置，只是用了它的角色素材。

## 要求

- macOS（Darwin 25 上开发；Intel 和 Apple Silicon 都没专门测）
- Hana 1.1.7-beta 或更新
- 不需要装任何依赖

**Windows 用不了。** Hana 有 Windows 版，但桌宠是 Swift + AppKit 写的，只有 macOS 构建。Windows 上装控制台只会看到「离线」。

## 装

1. 从 [Releases](../../releases) 下载 `app-hana-desktop-pet-*.zip`，在 Hana 里本地安装，**批准 `app/sessions.read` 权限**（不批的话会话列表里全是「会话」）。
2. 下载 `HanaDesktopPet-crosspet-*.zip`，解压双击 `.app`。第一次会被系统拦，提示「无法验证开发者」——右键 → 打开，或去「系统设置 → 隐私与安全性」点「仍要打开」。
3. 控制台里打开「本机桌宠连接」，状态变「已连接」就好了。

## 玩

- 单击角色：开心一下
- 按住拖动：挪位置
- 右键：换角色、锁定位置、停靠到角落、退出
- 控制台里：手动选角色，或把桌宠**钉在某条对话上**只跟它

默认跟「最近有活动的会话」。钉住之后，别的会话再热闹也抢不走。

## 会做什么

| Hana 那边 | 桌宠 |
|---|---|
| 空闲 | 待机，隔几秒换姿势、眨眼 |
| 空闲 5 分钟 | 打盹 |
| 生成文字 | 思考 |
| 读文件 / 抓网页 | 看书 |
| 写 / 改文件 | 写字 |
| 搜网页 / 搜文件 | 查找 |
| 跑命令 / 构建测试 | 奔跑 |
| 派活给别的会话 | 派活 |
| 生图 | 画画 |
| 连续工作 10 分钟 | 疲惫 |
| 10 秒连调 5 次工具 | 忙翻 |
| 某个工具成功 | 开心一下（2.5 秒） |
| 某个工具出错 | 失误（2.5 秒） |
| 整轮收工 | 得意 |
| 弹确认框等你点 | 询问 |
| 上下文压缩中 | 压缩 |
| 你插的话被丢弃 | 惊讶 |

认不出的工具名一律退回「通用忙碌」，不猜。

## 隐私

**桌宠只知道在干什么，不知道说了什么。**

只传会话 ID、标题、Agent 名称、状态、工具名、时间戳。没有正文、没有工具参数、没有工具结果、没有文件路径、没有提示词。

控制台虽然有 `app/sessions.read`，但只读标题和 Agent 名，不读历史消息。

## 已知问题

- **本地端口没鉴权**：`127.0.0.1:43127` 是明文 HTTP，没有令牌。同机任何程序都能灌假数据让它假装在干活。**别把它当可信的状态显示器**，它只是氛围。
- **没签名没公证**：每次更新后第一次打开可能被系统拦。
- **控制台和桌宠必须版本配套**：协议是 v3，只升其中一个会导致桌宠完全不响应——不是坏了，是新版在主动拒绝旧版。两个一起换。
- **不自动启动**：每次开机要自己开。
- **只验过合成数据**：逻辑测得很细（姿态 404 项、跨层 229 项、核心 16 项、控制台 108 项），但真实桌面的观感、拖动手感、鼠标穿透只有作者自己看过。
- **会话归属偶尔识别不出来**：会显示成「未识别会话」，不冒充真实会话，也不能被钉住。

## 自己构建

```sh
sh tools/run-checks.sh      # 全部本地检查，不启动 GUI、不安装、不连真实 Hana
sh tools/package-pet-app.sh # 打桌宠 .app
```

打出来的 `.app` 用 ad-hoc 签名，本机可用，分发出去会被 Gatekeeper 拦。
